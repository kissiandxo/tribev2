# Brand SERP Audit Sheet — Setup Instructions

Create this as a Google Sheet tab named "SERP Audit Log".

## Columns

| Column | Description |
|--------|-------------|
| `date` | ISO date of audit (auto-filled by workflow) |
| `serp_score` | X/10 — how many page-1 positions owned |
| `position_1_website` | ✅ / ❌ — is official website at #1? |
| `position_2_inner` | ✅ / ❌ — inner page ranking? |
| `knowledge_panel` | present / absent / partial |
| `map_pack` | ✅ / ❌ — in 3-pack? |
| `position_4_youtube` | ✅ / ❌ |
| `position_5_linkedin` | ✅ / ❌ |
| `position_6_facebook` | ✅ / ❌ |
| `position_7_instagram` | ✅ / ❌ |
| `position_8_press` | ✅ / ❌ |
| `position_9_directory` | ✅ / ❌ |
| `position_10_community` | ✅ / ❌ |
| `gaps_count` | Number of gaps detected |
| `top_priority_fix` | Claude's top recommended action |
| `auto_fixes_applied` | Number of assets auto-created this week |
| `notes` | Manual notes |

## Target Milestones

| Score | Status |
|-------|--------|
| 10/10 | 🏆 LOCKED DOWN — competitor has nowhere to appear |
| 8–9/10 | ✅ Strong — 1-2 positions to fill |
| 6–7/10 | ⚠️ Decent — meaningful gaps |
| Below 6 | 🚨 Urgent — significant exposure |

## How to Interpret

When your SERP score is 10/10, someone searching your business name sees:
- Your website in position 1
- Another page of your site in position 2-3
- Your Knowledge Panel card on the right (brand recognition)
- Your GBP in the map pack (call, directions, reviews all visible)
- Your YouTube video (visual brand reinforcement)
- LinkedIn (professional credibility)
- Facebook (social proof)
- Instagram (personality, visual work)
- A press article (editorial authority)
- A directory listing (third-party validation)

**Result:** Zero blank space for a competitor, negative article, or unknown result to appear. You own the entire first impression.
